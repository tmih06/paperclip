## Recovery method

Surviving parent and subagent tool journals supplied complete file snapshots,
file writes and exact replacements. Replacement context had to match uniquely.
Partial snapshots were not spliced into potentially shifted source. Recorded
shell commands were not executed. Ten reviewed, manifest-only JavaScript
transforms were recovered in a filesystem-confined interpreter.

This is partial source recovery, not a completed or verified migration. The
replay recorded 59 context or unavailable-source failures, some of which may be
superseded by later complete snapshots. Original lockfiles generated by commands,
file deletions, executable-mode changes, source-proof identities and original
commit history need independent reconciliation. Do not publish from this tree.
